# Support

## Questions and usage help

Start with the [README](README.md) and the [documentation index](docs/README.md).
Search existing issues before opening a new one. If the answer is still
missing, open a blank issue with the relevant environment, the outcome you want,
and what you already tried.

## Bugs and proposals

Use the structured issue forms:

- **Bug report** for reproducible incorrect behavior.
- **Feature request** for a user problem or desired outcome.
- **Documentation** when a page, command, example, or diagram is missing or
  incorrect.

Please keep one problem per issue and attach the smallest useful reproduction.

## Security and private data

Do not put vulnerabilities, credentials, tokens, private calendar or profile
data, or exploit details in a public issue. Follow [SECURITY.md](SECURITY.md)
and use GitHub's private reporting channel instead.
