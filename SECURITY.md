# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** button in this repository's
Security tab. Private vulnerability reporting keeps details out of public
issues while a fix is prepared.

Do not include credentials, personal data, or exploit details in a public issue.
If the report concerns a leaked credential, revoke it first and then include
only the provider and affected scope in the private report.

## Scope

Reports about executable code, prompt-injection risks, unsafe file handling,
and generated-output injection are in scope. Dependency alerts and secret
scanning are also enabled for this repository.
